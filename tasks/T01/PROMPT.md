# T01 HDC Prompt — Canonical Meta-Model

## Mission

Build the AIOS Canonical Meta-Model under Human authority and T00 HDC Guard.

## Execution order

UNDERSTAND
→ DISCOVER EXISTING
→ MODEL
→ CONTRACT
→ ARCHITECT
→ HUMAN GATE
→ IMPLEMENT
→ TEST
→ VERIFY
→ REPLAY
→ EVIDENCE
→ HUMAN ACCEPTANCE

## Required implementation direction

The implementation must establish machine-verifiable canonical contracts
for the shared AIOS structural language.

The implementation must preserve these distinctions:

- Identity != Role
- Role != Authority
- Capability != Authority
- Evidence != Decision
- AI Recommendation != Human Decision
- Domain != Organization Unit
- Current State != History

The implementation must not hard-code Organization structure into Domain
definitions and must not introduce business-domain runtime.

## Human authority

Human owns:
- purpose
- institutional meaning
- authority
- acceptance

AI owns:
- discovery
- model preparation
- contracts
- architecture preparation
- implementation
- tests
- verification
- replay
- engineering evidence

No implementation may be represented as accepted without separate Human
Acceptance evidence.
