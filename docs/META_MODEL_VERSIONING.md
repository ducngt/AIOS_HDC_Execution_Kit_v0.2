# AIOS Canonical Meta-Model Versioning

The Canonical Meta-Model uses semantic versioning.

- PATCH: compatible clarification or non-breaking correction.
- MINOR: backward-compatible extension.
- MAJOR: breaking canonical contract change.

Canonical references identify their target explicitly and may declare a
version constraint.

Historical objects and provenance must remain interpretable after compatible
model evolution. Breaking evolution requires migration and explicit HDC
change governance.
